# Yash Taywade — Portfolio

Premium React + Vite portfolio starter.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
npm run preview
```

## Before deployment

1. Put your real resume PDF at `public/YASH_TAYWADE.pdf`.
2. Replace project GitHub links with individual repository URLs.
3. Add project screenshots if desired.
4. Deploy to Vercel, Netlify, or GitHub Pages.
